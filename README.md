## 🚀 Cómo Desplegar a GitHub Pages en 2 Clics

1. Sube este repositorio a tu cuenta de GitHub como repositorio **Público** (ejemplo: `taller-antigravity-web`).
2. Ve a **Settings > Pages**.
3. En **Branch**, selecciona **`main`** y carpeta **`/ (root)`**.
4. Haz clic en **Save**.
5. En 60 segundos tu sitio web estará en vivo en:
   ```text
   https://gersonja.github.io/taller-antigravity-web/
   ```
